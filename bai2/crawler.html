Crawler bài viết từ URL

Quản lý dữ liệu bài viết

Trang web tự nạp bài viết có sẵn từ data/posts.json khi mở lần đầu. Bạn vẫn có thể nhập bổ sung file JSON riêng từ Bài 1 hoặc xuất dữ liệu để sao lưu.

Cách hoạt động: Nhập đường dẫn bài viết công khai, nhấn Crawl dữ liệu để trích xuất JSON, rồi nhấn Lưu vào LocalStorage. Chức năng crawler chạy qua API trên cùng website online, không cần mở VS Code hay chạy Python trên máy người dùng. Không hỗ trợ trang yêu cầu đăng nhập hoặc chặn tự động hóa.
